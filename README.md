AllMCPs provides a definitive directory for discovering and installing Model Context Protocol (MCP) servers. Users can browse, search, and filter thousands of MCP server listings to find suitable integrations for AI agents like Claude and Cursor. The platform offers tools, documentation, and a searchable API to integrate MCP data into applications, enhancing AI capabilities across various use cases.

**Areas:** Directory · Model Context Protocol · AI Agents · Developer Tools · Search & Data Extraction · Finance & Fintech · Communication · Knowledge & Memory

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for AllMCPs: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
